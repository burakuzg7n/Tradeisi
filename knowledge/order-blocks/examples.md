# Order Blocks — Örnekler

## Örnek 1: Bullish OB Tespiti ve Entry

```
4H chart:
  Mum A: Bearish (red), High=50.000, Low=49.500
  Mum B: Büyük bullish hareket → BOS oluştu (swing high kırıldı)

→ Mum A = Bullish Order Block
  OB zone: 49.500 - 50.000
  Midpoint: 49.750

Senaryo:
  Fiyat 51.500'e yükseldi (BOS)
  Geri dönerek OB'ye 49.700'de dokundu (midpoint altı henüz değil)
  15M CHoCH yukarı oluştu
  
ENTRY: 49.720
STOP: 49.480 (OB low altı)
TARGET: 51.500 (swing high / BSL)
RR: (51.500 - 49.720) / (49.720 - 49.480) = 1780/240 = 7.4R
```

## Örnek 2: OB + FVG Confluence

```
4H Bullish OB: 48.000 - 48.500
4H Bullish FVG: 48.200 - 48.700

Çakışma bölgesi: 48.200 - 48.500 (güçlü zone)

→ Entry bu bölgeye retest gelince aranır
→ Stop: 47.950 (OB low altı)
→ Bu bölge hem OB hem FVG → "confluence zone" → yüksek güven
```

---

## Örnek 3: Breaker Block

```
Bullish OB: 47.000 - 47.500
Fiyat OB içine girdi ve 46.800'e düştü → OB kırıldı

Artık bu bölge Bearish Breaker Block: 47.000 - 47.500
Fiyat tekrar 47.200'e çıkarsa → short entry noktası
```

---

## Örnek 4: Geçersiz OB (BOS Yok)

```
Kırmızı mum: High=50.100, Low=49.800
Sonrasında fiyat sadece 50.200'e çıktı (swing high kırılmadı)
→ BOS oluşmadı → Bu mum OB DEĞİL
→ İşaretleme yapılmaz
```
