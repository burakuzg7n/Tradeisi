# Order Blocks — Concept

## Temel Tanım

Order Block (OB), kurumsal oyuncuların büyük emirlerini yerleştirdiği son mum bölgesidir. Fiyat bir Order Block'tan güçlü bir hareket yaparsa, o bölgeye döndüğünde yeniden talep/arz görmesi beklenir.

**Basit tanım:** BOS veya CHoCH öncesindeki son karşı yönlü mum.

---

## Bullish Order Block

- Bullish BOS öncesindeki **son bearish (kırmızı) mum**
- Bu mum bölgesi, kurumsal alım emirlerinin biriktiği yerdir
- Fiyat bu bölgeye döndüğünde long entry için potansiyel

```
... bearish mum (OB) → büyük bullish hareket → BOS → ...
     ^^^^^^^
     Bu bearish mum = Bullish Order Block
     Bölge: mum'un High ile Low arasındaki alan
```

---

## Bearish Order Block

- Bearish BOS öncesindeki **son bullish (yeşil) mum**
- Kurumsal satış emirlerinin biriktiği yer

```
... bullish mum (OB) → büyük bearish hareket → BOS → ...
     ^^^^^^^
     Bu bullish mum = Bearish Order Block
```

---

## OB ile FVG Farkı

| Özellik | Order Block | FVG |
|---------|-------------|-----|
| Oluşum | Tek mum bölgesi | 3 mumlu boşluk |
| Mekanizma | Emir yoğunluğu | Fiyat boşluğu |
| Güç | Hacim varsa çok güçlü | İmbalance kaynaklı |
| Birlikte | OB içinde FVG varsa → güçlü confluence | ← |

---

## Breaker Block

Bir Order Block başarısız olursa (fiyat OB'yi kırarsa), o OB **Breaker Block**'a dönüşür:
- Bullish OB kırılınca → Bearish Breaker (artık direnç)
- Bearish OB kırılınca → Bullish Breaker (artık destek)

---

## Confluence: OB + FVG

En güçlü setup: Order Block bölgesi içinde FVG de bulunuyorsa:
- OB fiyat zone'u → kurumsal ilgi
- İçindeki FVG → imbalance, filling beklentisi
- İkisi çakışıyorsa → yüksek olasılıklı entry noktası

---

## Geçerlilik Kriterleri

Bir OB geçerlidir eğer:
1. Ardından güçlü BOS veya CHoCH oluşmuşsa
2. Henüz mitigate edilmemişse (fiyat içine girmemişse)
3. HTF bias ile hizalıysa

---

## OB Mitigasyon

- Fiyat OB içine girdiğinde "mitigate" olmaya başlar
- OB'nin %50'si geçilirse güç azalır
- OB tamamen geçilirse geçersiz → Breaker Block olur
