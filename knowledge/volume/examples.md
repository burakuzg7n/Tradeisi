# Volume — Örnekler

## Örnek 1: BOS + Hacim Konfirmasyonu

```
Swing high: 50.000
BOS mumu: close 50.200 (kırdı), hacim = ortalama 3x → güçlü BOS
→ Trend devamı yüksek ihtimal
```

Karşılaştırma:
```
BOS mumu: close 50.050 (çok zayıf kırılım), hacim = ortalama 0.4x → şüpheli
→ Beklenir, yeniden test izlenir
```

## Örnek 2: SSL Sweep + Hacim Spike

```
Swing low: 48.500
Sweep mumu: low 48.200, close 48.700
Hacim: o gün ortalama 4.2x

→ Kurumsal alım var → sweep güvenilir → long aranır
```

---

## Örnek 3: CVD Divergence

```
Fiyat: 51.000 → 52.000 → 53.000 (HH zinciri)
CVD:   1000   → 900    → 750  (azalıyor)

→ Bearish divergence
→ Fiyat yükseliyor ama alım baskısı azalıyor
→ Yakın reversal sinyali → long trade kaçınılır, short hazırlığı
```

---

## Örnek 4: Volume Profile ile Entry Refinement

```
4H OB: 49.000 - 49.500
Volume Profile POC bu bölge için: 49.200

→ En yoğun işlem 49.200'de → en güçlü destek
→ Entry 49.200-49.250 daha iyi (POC yakını)
→ Stop: 48.950
```
