# Market Structure — Örnekler

## Örnek 1: Bullish Trend Okuma

```
Fiyat hareketi (soldan sağa):
  100 → 110 (HH) → 105 (HL) → 115 (HH, BOS) → 108 (HL) → 120 (HH, BOS)
```

Yorum:
- HH ve HL zinciri devam ediyor → bullish trend sağlam
- Her BOS sonrası oluşan HL, long entry için potansiyel nokta
- HTF bu yapıyı gösteriyorsa LTF'de only long

---

## Örnek 2: CHoCH Tespiti

```
Bearish trend:
  120 → 112 (LH) → 105 (LL) → 108 (LH) → 100 (LL) → 111 (LH kırıldı!)
                                                         ^ CHoCH (bullish)
```

Yorum:
- Bearish trende son LH 108'di
- Fiyat 111'e çıkarak 108'i kırdı → Bullish CHoCH
- Bu BOS değil, trend değişim sinyali
- Hemen long değil: CHoCH sonrası HL oluşmasını bekle, sonra entry

---

## Örnek 3: HTF + LTF Kombinasyonu

**4H (HTF):** Bullish BOS var, HL oluşuyor → Bias: BULLISH  
**15M (LTF):** Fiyat 4H HL seviyesine geri döndü, 15M CHoCH yukarı oluştu

→ **Long entry geçerli.** HTF ve LTF hizalanmış.

---

## Örnek 4: Geçersiz Setup (HTF Karşı)

**4H (HTF):** Bearish trend, LH-LL zinciri devam ediyor  
**15M (LTF):** Küçük bullish CHoCH oluştu

→ **Long entry YANLIŞ.** HTF bearish, 15M gürültüsüne bakıp long alma.  
→ Doğru aksiyon: 15M bearish yapı aranır, short kurulur.

---

## Örnek 5: Range Tespiti

```
Fiyat: 50000 - 52000 arası 20 mum sıkışmış
  Swing Highs: 51900, 51950, 51980 → yakın seviyeler
  Swing Lows: 50050, 50020, 50080 → yakın seviyeler
```

Yorum:
- HH-HL veya LH-LL zinciri yok → range
- Sistem bu durumda trade üretmez
- 52000 kırılırsa bullish BOS → short bias sonlanır
- 50000 kırılırsa bearish BOS → trend başlar
